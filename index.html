    Contact cards are written into the code as a vCard 3.0. iPhone Camera, Android Camera and Google Lens read it and offer Add to contacts. Name, phones, emails, sites and socials land in the right fields.

    Everything is stored inside the code itself, so it works offline and forever with no server and no tracking. The flip side: a printed code can't be re-pointed. Reprint, or point a Link code at a page you can edit.
